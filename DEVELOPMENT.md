## Game Architecture

### Classes

#### DevOpsGame
Main game controller class
- **Methods**:
  - `__init__()` - Initialize game state
  - `play()` - Main game loop
  - `ask_challenge()` - Present a challenge
  - `display_status()` - Show current stats
  - `end_game()` - Display results

#### Challenge (DataClass)
Represents a single challenge
- `title` - Challenge title
- `description` - Scenario description
- `difficulty` - Severity level
- `correct_answer` - Answer key (A-D)
- `options` - List of 4 options
- `lesson` - Educational content

#### DevOpsRole (Enum)
Player role selection
- JUNIOR_DEV (50 HP)
- DEVOPS_WARRIOR (100 HP)
- KUBERNETES_WIZARD (150 HP)

#### Severity (Enum)
Challenge difficulty levels
- LOW (1x multiplier)
- MEDIUM (2x multiplier)
- CRITICAL (3x multiplier)
- ABSOLUTE_DISASTER (4x multiplier)

### Game Mechanics

**Scoring System**
- Points = Difficulty × 10
- Max points per challenge: 40
- Total max score: 320 points

**Stability System**
- Starts at 50%
- Correct answer: +5% × difficulty
- Wrong answer: -5% × difficulty
- Max: 100%, Min: 0%

**Health System**
- Role-dependent starting health
- Damage on wrong answers: 10 × difficulty
- Game over when health ≤ 0

## Adding New Challenges

### Step 1: Create Challenge Object
```python
Challenge(
    title="🎯 Challenge Title",
    description="Scenario description that sets up the problem",
    difficulty=Severity.MEDIUM,
    correct_answer="B",
    options=[
        "A) Incorrect option 1",
        "B) Correct option",
        "C) Incorrect option 2",
        "D) Incorrect option 3"
    ],
    lesson="✨ LESSON: Key concept to learn from this challenge"
)
```

### Step 2: Add to _load_challenges()
Insert the Challenge object into the list returned by `_load_challenges()` method.

### Step 3: Write Tests
```python
def test_new_challenge():
    game = DevOpsGame()
    # Find and test your challenge
    assert any(c.title == "Your Title" for c in game.challenges)
```

### Step 4: Submit PR
- Include challenge in PR description
- Ensure all tests pass
- Update documentation if needed

## Troubleshooting

### Local Tests Fail
```bash
# Ensure correct Python version
python --version  # Should be 3.10+

# Reinstall dependencies
pip install --upgrade pip
pip install -r requirements.txt

# Run tests with verbose output
pytest test_game.py -v -s
```

### Build Fails in CI/CD
1. Check workflow logs: GitHub Actions → workflow run
2. Common issues:
   - Python version mismatch
   - Missing dependencies
   - Test failures

### Game Won't Run
```bash
# Check Python installation
python --version

# Verify all dependencies
pip list | grep pytest

# Try running directly
python -m game
```
